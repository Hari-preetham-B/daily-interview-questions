**You have a Random Forest regressor for predicting house prices. How would you use cross-validation to tune its hyperparameters (e.g., number of trees, max depth, min samples split)? What pitfalls might arise when the dataset is small, and how can you mitigate them?**

<details>
<summary>💡 Hint</summary>

Think about separating the data for hyperparameter search from the data used for final performance estimation, and how randomness in tree building can affect results.

</details>

<details>
<summary>✅ Answer</summary>

Use a nested CV: an outer loop splits the data into training and hold‑out sets to estimate generalisation, while an inner loop performs grid or random search over the hyperparameter space using k‑fold CV on the training split. For small datasets, the validation score can be very noisy and the outer test set may be too small; mitigate this by using leave‑one‑out or repeated k‑fold CV, ensuring each split has enough samples, and optionally using Bayesian optimisation to reduce the number of evaluations. Also set a random seed and, if the target distribution varies, use stratified or quantile‑based splits to keep each fold representative.

</details>
