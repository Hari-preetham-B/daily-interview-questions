# 2026-11-25 AM — AIML (Medium)

## Question
Suppose you are training a support vector machine (SVM) with an RBF kernel on a medium‑size tabular dataset.  How would you go about selecting an appropriate kernel bandwidth (γ) using cross‑validation, and what is the expected impact of a very small versus a very large γ on the model’s bias‑variance trade‑off?

## Hint
Think about how the kernel width controls the locality of each support vector and how cross‑validation can help find a sweet spot.  Remember that extreme values can lead to over‑ or under‑fitting.

## Answer
To choose γ, set up a grid (e.g., 2⁻⁹ to 2⁴) and perform k‑fold cross‑validation for each value, recording the validation error.  Pick the γ that minimizes the cross‑validated loss, optionally using a validation curve to visualize the bias‑variance trend.  A very small γ (narrow kernel) makes each support vector influence only a tiny region, leading to a highly flexible model that captures noise (low bias, high variance).  Conversely, a very large γ (wide kernel) turns the decision surface into a smooth, almost linear function, reducing variance but increasing bias and potentially under‑fitting the data.
