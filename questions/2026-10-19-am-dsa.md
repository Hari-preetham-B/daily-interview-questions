# 2026-10-19 AM — DSA (Medium)

## Question
Given the root of a binary tree, return the length of its diameter. The diameter is defined as the number of edges between the two farthest nodes in the tree (the path may or may not pass through the root).

## Hint
Think about computing the height of each subtree while tracking the longest path that passes through the current node.

## Answer
Perform a post‑order DFS. For each node compute its left and right subtree heights. The diameter candidate at that node is leftHeight + rightHeight. Keep a global maximum of these candidates. Return the global maximum after traversal. The height of a node is 1 + max(leftHeight, rightHeight), with a leaf having height 1. This runs in O(n) time and O(h) space for recursion depth.
