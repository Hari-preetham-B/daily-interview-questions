## 📅 Today's Questions — 2026-10-07

### 🌅 Morning (2026-10-07) — DSA

**Given an integer array `nums` representing the amount of money in each house along a street, determine the maximum amount of money you can rob without robbing two adjacent houses. Return the maximum sum you can obtain.**

<details>
<summary>💡 Hint</summary>

Think about making a choice at each house: either rob it and skip the previous one, or skip it and keep the best total so far. Use dynamic programming with O(1) extra space.

</details>

<details>
<summary>✅ Answer</summary>

Use a DP where `dp[i]` is the max money that can be robbed from the first `i` houses. The recurrence is `dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`. Initialize `prev2 = 0` (dp[0]) and `prev1 = nums[0]` (dp[1]) handling empty array separately. Iterate through the array updating `curr = max(prev1, prev2 + nums[i])`, then shift `prev2 = prev1` and `prev1 = curr`. After the loop, `prev1` holds the answer. This runs in O(n) time and O(1) space.

</details>
