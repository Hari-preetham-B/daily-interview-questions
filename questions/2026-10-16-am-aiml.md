## Question
Explain the concept of weight sharing in convolutional neural networks. How does it reduce the number of parameters compared to fully connected layers, and what effect does this have on translation invariance in image processing?

## Hint
Think about how the convolution operation slides a kernel across an image and reuses the same weights.

## Answer
Weight sharing in a CNN means that the same filter weights are applied at every spatial location when computing the convolution. This drastically reduces parameters because a filter of size k×k×C has k^2×C parameters regardless of the input image size, whereas a fully connected layer would need one weight per input-output pair. Because the filter is reused across the image, the network responds similarly to a feature wherever it appears, giving the model approximate translation invariance. The receptive field grows with depth and pooling, allowing higher layers to capture larger patterns while still maintaining a small parameter count.
