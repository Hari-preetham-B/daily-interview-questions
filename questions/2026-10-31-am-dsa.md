# 2026-10-31 AM — DSA (Medium)

## Question
Given a string s and an integer k, find the length of the longest substring of s that contains at most k distinct characters. Return 0 if no such substring exists.

## Hint
Use a sliding window and a hash map (or array) to track character frequencies. Expand the right pointer while the distinct count ≤ k, and shrink from the left when it exceeds k.

## Answer
Maintain two pointers left and right defining the current window and a hash map counting characters in the window. As right moves forward, add s[right] to the map; if the map size exceeds k, move left forward, decrementing counts and removing characters with zero frequency. Keep track of the maximum window size seen whenever the map size ≤ k. This runs in O(n) time with O(k) extra space, where n is the length of s.
