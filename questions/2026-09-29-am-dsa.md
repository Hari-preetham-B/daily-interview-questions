# 2026-09-29 AM — DSA (Medium)

## Question
Given a string consisting only of '(' and ')', return the length of the longest substring that forms a valid (well‑balanced) set of parentheses. Aim for O(n) time and O(1) extra space.

## Hint
Consider scanning the string while keeping track of the last index where a mismatch occurred, and use a counter to record unmatched '(' positions.

## Answer
Use a single pass with two counters. First scan left‑to‑right: increment a left counter for '(' and a right counter for ')'. When left==right, update maxLen = max(maxLen, 2*right). If right exceeds left, reset both counters to zero. Then scan right‑to‑left repeating the same logic with roles swapped (right counter first). The maximum length found in either pass is the answer. This runs in O(n) time and O(1) extra space.
