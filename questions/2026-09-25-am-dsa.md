# 2026-09-25 AM — DSA (Medium)

## Question
You are given an integer array arr consisting only of 0s and 1s. Find the length of the longest contiguous subarray that contains an equal number of 0s and 1s.

## Hint
Treat 0 as -1 and compute a running sum. Whenever the same sum reappears, the subarray between the two indices has equal numbers of 0s and 1s.

## Answer
Convert every 0 to -1 and compute a prefix sum array. Use a hash map to store the first index at which each sum occurs. While iterating, if the current sum has been seen before, the subarray between the previous index+1 and the current index has equal 0s and 1s, so update the maximum length. Return the maximum length found; if no such subarray exists, return 0.
