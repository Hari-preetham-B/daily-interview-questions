## Question
What is focal loss and how does it help in training object detection models on highly imbalanced datasets? Provide its mathematical definition, explain the role of its hyperparameters “…”

## Hint
Think about how the loss can be modulated based on the model’s confidence in the prediction.

## Answer
Focal loss is a modified cross‑entropy loss that adds a modulating factor to down‑weight easy examples and focus learning on hard negatives. For a binary classification case with true label y∈{0,1} and predicted probability p, focal loss is defined as: FL(p_t) = -α (1−p_t)^γ log(p_t), where p_t = p if y=1 and p_t = 1−p if y=0. The hyperparameter α balances class importance (often set to 0.25 for the minority class), while γ (>0) controls the focusing effect: larger γ gives more weight to hard, misclassified examples. In object detection, this loss reduces the overwhelming influence of abundant background (negative) samples, allowing the model to learn more effectively from scarce foreground (positive) instances.
