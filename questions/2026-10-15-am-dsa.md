## Question
Given an m × n integer matrix (which may contain negative numbers), find the submatrix with the maximum possible sum and return that sum. Aim for a solution with O(m·n²) time complexity.

## Hint
Fix two rows (or columns) as the top and bottom boundaries, collapse the matrix between them into a 1‑D array of column sums, and then apply the linear‑time maximum subarray algorithm on that array.

## Answer
The optimal approach runs in O(m·n²) by iterating over all pairs of rows as the top and bottom of the submatrix. For each pair, we maintain a temporary array `colSum` where `colSum[j]` accumulates the sum of elements in column j between the two rows. Applying Kadane's algorithm on `colSum` yields the maximum subarray sum for that row pair, which corresponds to the best submatrix for those boundaries. We keep the global maximum over all row pairs. The overall time is O(m·n²) and the extra space is O(n). Example Python implementation:
python
def maxSumSubmatrix(matrix):
    if not matrix or not matrix[0]:
        return 0
    m, n = len(matrix), len(matrix[0])
    max_sum = float('-inf')
    for top in range(m):
        col_sum = [0] * n
        for bottom in range(top, m):
            for c in range(n):
                col_sum[c] += matrix[bottom][c]
            # Kadane's algorithm on col_sum
            cur = 0
            best = float('-inf')
            for val in col_sum:
                cur = max(val, cur + val)
                best = max(best, cur)
            max_sum = max(max_sum, best)
    return max_sum
