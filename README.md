### 🌅 Morning (2026-11-21) — AIML

**Explain how permutation importance is used to assess feature importance in a trained model, and compare it with SHAP values. In what situations might permutation importance give misleading results, and how can SHAP mitigate those issues?**

<details>
<summary>💡 Hint</summary>

Think about how permutation importance perturbs feature values and measures performance change, versus SHAP’s game‑theoretic attribution. Consider feature correlations and model non‑linearity.

</details>

<details>
<summary>✅ Answer</summary>

Permutation importance evaluates a feature’s importance by randomly permuting its values in the validation set and measuring the drop in model performance; a large drop indicates the feature is influential. SHAP values, derived from Shapley values in cooperative game theory, assign each feature a contribution to the prediction by considering all possible feature combinations, thus providing a local, consistent explanation. Permutation importance can be misleading when features are highly correlated: permuting one feature may have little effect because other correlated features still carry the same information, underestimating its importance. SHAP mitigates this by accounting for feature interactions and correlations through its exhaustive coalition consideration, giving more reliable attribution even in correlated settings.

</details>
