### 🌅 Morning (2026-09-10) — AIML

**Explain the Kernel Trick in Support Vector Machines (SVMs). How does it allow SVMs to learn non-linear decision boundaries without explicitly mapping data points to a high-dimensional feature space, and what requirement must a function satisfy to be a valid kernel (Mercer's Condition)?**

<details>
<summary>💡 Hint</summary>

Think about how SVM optimization relies solely on inner products of data points, and how Mercer's theorem guarantees those inner products correspond to a valid feature space.

</details>

<details>
<summary>✅ Answer</summary>

The Kernel Trick enables linear models like Support Vector Machines to separate non-linearly separable data by implicitly mapping input vectors into a higher-dimensional (or infinite-dimensional) feature space. Since the dual formulation of the SVM optimization problem depends only on the dot products between data samples, a kernel function $K(x_i, x_j)$ can compute this dot product directly as $\langle\Phi(x_i), \Phi(x_j)\rangle$ without ever explicitly computing the high-dimensional mapping $\Phi(x)$. This reduces the computational complexity from $O(D)$ in the transformed space $D$ back to efficient operations in the original input dimension $d$. For a function to be a valid Mercer kernel, its Gram matrix across any arbitrary set of points must be symmetric and positive semi-definite, guaranteeing that an underlying inner-product feature space exists.

</details>
