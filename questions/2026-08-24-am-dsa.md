# 2026-08-24 AM — DSA (Medium)

## Question
Given an array of intervals where intervals[i] = [start_i, end_i], merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

## Hint
Try sorting the intervals by their start times first. How does this help in identifying overlaps sequentially?

## Answer
First, sort the array of intervals by their start times in ascending order. Initialize a list `merged` to store the result. Iterate through each interval: if `merged` is empty or the start time of the current interval is greater than the end time of the last interval in `merged`, add the current interval to `merged`. Otherwise, there is an overlap, so merge them by updating the end time of the last interval in `merged` to max(last_interval.end, current_interval.end). The time complexity is O(N log N) due to sorting, and the space complexity is O(N) or O(log N) depending on the sorting algorithm implementation.
