### 🌅 Morning (2026-11-20) — DSA

**Given a directed acyclic graph (DAG) represented as an adjacency list, and two distinct nodes `source` and `target`, count the number of distinct directed paths from `source` to `target`. Return the count as an integer (you may assume it fits in a 64‑bit signed integer).**

<details>
<summary>💡 Hint</summary>

Topologically sort the DAG first, then use dynamic programming to accumulate the number of ways to reach each node from the source.

</details>

<details>
<summary>✅ Answer</summary>

Perform a topological sort of the DAG (e.g., Kahn's algorithm). Create an array dp of size V initialized to 0 and set dp[source]=1. Process vertices in topological order; for each vertex u, for every outgoing edge (u,v) add dp[u] to dp[v] (dp[v] += dp[u]). After all vertices are processed, dp[target] holds the total number of distinct paths from source to target. This runs in O(V+E) time and O(V) extra space, and works because each path contribution is propagated forward exactly once in topological order.

</details>
