## Question
Given a string s, partition it into substrings such that each substring is a palindrome. Return the minimum number of cuts needed to split s into palindrome substrings.

## Hint
Pre‑compute a table that tells whether any substring s[i..j] is a palindrome, then use dynamic programming where dp[i] stores the best cut count for the prefix ending at i.

## Answer
We first build a boolean table isPal[n][n] where isPal[i][j] is true if s[i..j] is a palindrome. This can be filled in O(n^2) by checking s[i]==s[j] and isPal[i+1][j-1] (or handling length 1 and 2 separately). Then let dp[i] be the minimum cuts for s[0..i]. Initialize dp[i]=i (worst case: cut each character). For each i, if isPal[0][i] is true, dp[i]=0; otherwise, for each j<i, if isPal[j+1][i] is true we update dp[i]=min(dp[i], dp[j]+1). The answer is dp[n-1]. This runs in O(n^2) time and O(n^2) space (the palindrome table) or O(n) extra space if we compute palindromes on the fly. Example Python implementation:
python
def minCut(s: str) -> int:
    n = len(s)
    isPal = [[False]*n for _ in range(n)]
    for i in range(n-1, -1, -1):
        for j in range(i, n):
            isPal[i][j] = s[i]==s[j] and (j-i<2 or isPal[i+1][j-1])
    dp = [0]*n
    for i in range(n):
        if isPal[0][i]:
            dp[i] = 0
        else:
            dp[i] = i
            for j in range(i):
                if isPal[j+1][i]:
                    dp[i] = min(dp[i], dp[j]+1)
    return dp[-1]
