### 🌅 Morning (2026-11-05) — AIML

**Explain how you would evaluate a generative image model’s quality using Fréchet Inception Distance (FID). What are the main steps to compute it, and why is FID generally preferred over the Inception Score?**

<details>
<summary>💡 Hint</summary>

Think about extracting feature statistics from a fixed CNN and comparing distributions of real and generated images.

</details>

<details>
<summary>✅ Answer</summary>

FID measures the distance between two multivariate Gaussian distributions fitted to the feature activations of a pre‑trained Inception‑v3 network. To compute it, first pass a set of real images and a set of generated images through the network and record the mean vector μ_r, μ_g and covariance matrices Σ_r, Σ_g of the activations (usually from the pool3 layer). Then calculate FID = ||μ_r-μ_g||^2 + Tr(Σ_r + Σ_g - 2(Σ_rΣ_g)^{1/2}). It is preferred over Inception Score because it captures both the quality and diversity of samples, is invariant to the number of classes, and directly compares real vs. generated distributions rather than relying on classification confidence scores.

</details>
