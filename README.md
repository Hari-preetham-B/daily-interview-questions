### 🌅 Morning (2026-10-23) — DSA

**Given an integer array nums, find the maximum sum of any contiguous subarray that contains at most two distinct numbers. For example, in nums = [1,2,1,4,7,2,5], the subarray [1,4,7,2] has sum 14 and only contains the numbers 1,4,7,2? Actually 1,4,7,2 are four distinct, so not allowed. The best subarray is [4,7,2] with sum 13.**

<details>
<summary>💡 Hint</summary>

Use a sliding window with two pointers, keeping a hash map of element counts in the window and the current window sum. When the map grows to more than two distinct keys, shrink from the left until it returns to two.

</details>

<details>
<summary>✅ Answer</summary>

The optimal solution runs in O(n) time using two pointers and a hashmap. Initialize left = 0, sum = 0, maxSum = 0, and an empty dictionary freq. Iterate right from 0 to n-1: add nums[right] to sum and increment freq[nums[right]]. While len(freq) > 2, subtract nums[left] from sum, decrement freq[nums[left]] and remove the key if its count becomes zero, then increment left. After each step, update maxSum = max(maxSum, sum). Finally return maxSum.

Python implementation:
python
def maxTwoDistinct(nums):
    freq = {}
    left = 0
    cur_sum = 0
    best = 0
    for right, val in enumerate(nums):
        cur_sum += val
        freq[val] = freq.get(val, 0) + 1
        while len(freq) > 2:
            left_val = nums[left]
            cur_sum -= left_val
            freq[left_val] -= 1
            if freq[left_val] == 0:
                del freq[left_val]
            left += 1
        best = max(best, cur_sum)
    return best
