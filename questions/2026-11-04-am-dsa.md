## Question
Given an integer array `nums` and an integer `k`, return the total number of continuous subarrays whose sum equals `k`. The array may contain positive, negative, and zero values. Aim for O(n) time and O(n) extra space.

## Hint
Track the running prefix sum while iterating and use a hash map to count how many previous prefixes have a sum equal to (currentSum‑k).

## Answer
Initialize a hash map `count` with {0:1} to handle subarrays starting at index 0. Iterate through `nums`, maintaining a running sum `curr`. For each element, add `count.get(curr - k, 0)` to the answer, because any previous prefix with sum `curr‑k` forms a subarray summing to `k`. Then increment `count[curr]` by one. This yields O(n) time and O(n) space. Example Python implementation:
python
def subarraySum(nums, k):
    from collections import defaultdict
    prefix_counts = defaultdict(int)
    prefix_counts[0] = 1
    curr = ans = 0
    for x in nums:
        curr += x
        ans += prefix_counts[curr - k]
        prefix_counts[curr] += 1
    return ans
