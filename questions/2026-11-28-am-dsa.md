# 2026-11-28 AM — DSA (Medium)

## Question
Given an integer array nums and an integer K, return the length of the longest contiguous subarray whose sum is divisible by K. If no such subarray exists, return 0.

## Hint
Consider prefix sums modulo K and store the first occurrence of each remainder.

## Answer
Compute the running prefix sum and take it modulo K (adjusting for negatives). Keep a hash map that records the earliest index where each remainder appears. For each index i, if the same remainder was seen before at index j, the subarray (j+1..i) has a sum divisible by K; update the maximum length with i-j. Initialize the map with remainder 0 at index -1 to handle subarrays starting at the beginning. This algorithm runs in O(n) time and uses O(K) additional space.
