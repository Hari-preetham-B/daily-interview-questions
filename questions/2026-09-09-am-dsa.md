# 2026-09-09 AM — DSA (Medium)

## Question
You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money. Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1. You may assume that you have an infinite supply of each coin type.

## Hint
Think about building up the minimum coins needed for smaller target amounts from 0 to amount using Dynamic Programming.

## Answer
This problem can be solved using 1D Dynamic Programming in a bottom-up approach. Create an array `dp` of size `amount + 1` initialized to `amount + 1` (acting as infinity), and set `dp[0] = 0` since zero coins are needed to make an amount of 0. Iterate through all amounts `i` from 1 to `amount`, and for each coin denomination `c` in `coins`, if `i - c >= 0`, update `dp[i] = min(dp[i], dp[i - c] + 1)`. Finally, return `dp[amount]` if it is less than or equal to `amount`, otherwise return `-1`. This solution runs in O(amount * n) time and uses O(amount) space, where n is the number of coin denominations.
