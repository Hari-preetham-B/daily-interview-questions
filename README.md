# 🧠 Daily Interview Question Bot

Autonomous daily interview-prep log, generated by the Claude API. One new question
every day, rotating across **DSA**, **AI/ML**, **CSE Core**, and **Behavioral**
topics — no repeats, no manual effort.

This README updates itself automatically every day. Run the workflow once
(Actions tab → "Daily Interview Question" → Run workflow) or wait for the
scheduled run to see today's question here.

See [SETUP.md](SETUP.md) for one-time setup instructions.
