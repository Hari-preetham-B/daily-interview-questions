# 2026-11-24 AM — DSA (Hard)

## Question
Given an undirected graph represented as an adjacency list, write a function that returns the number of articulation points (cut vertices) in the graph. A vertex is an articulation point if removing it and its incident edges increases the number of connected components. The graph has N vertices labeled 0..N-1 and may be disconnected.

## Hint
Use a depth‑first search and keep track of discovery times and low values to identify critical vertices.

## Answer
Use Tarjan’s algorithm: run a DFS, assign each vertex a discovery time and compute low[v] = min(discovery[v], discovery[w]) for back edges and low[w] for child w. A vertex v (except root) is an articulation point if it has a child w such that low[w] >= discovery[v]. The root is an articulation point if it has more than one child. Count such vertices. The algorithm runs in O(V+E) time and O(V) space.
