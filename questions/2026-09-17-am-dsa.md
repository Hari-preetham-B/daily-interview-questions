# 2026-09-17 AM — DSA (Medium)

## Question
Given an integer array `nums`, return the length of the longest strictly increasing subsequence.

## Hint
Can you maintain an auxiliary array representing the smallest tail of all increasing subsequences of each length found so far, using binary search to update it?

## Answer
To solve this in O(n log n) time, maintain an array `tails` where `tails[i]` stores the smallest ending element among all increasing subsequences of length `i + 1`. For each number `x` in `nums`, use binary search to find the smallest element in `tails` that is greater than or equal to `x`. If such an element exists, replace it with `x` (this lowers the potential tail for future subsequences). If `x` is larger than all elements in `tails`, append `x` to `tails`. The length of `tails` at the end gives the length of the longest increasing subsequence. The space complexity is O(n).
