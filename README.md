### 🌅 Morning (2026-10-08) — AIML

**Explain temperature scaling as a model calibration technique: how it works, why it does not alter the predicted class order, and how the temperature parameter is typically determined.**

<details>
<summary>💡 Hint</summary>

Consider how scaling the logits before softmax changes the probability distribution but keeps the relative ordering of scores.

</details>

<details>
<summary>✅ Answer</summary>

Temperature scaling is a simple post‑processing method that adjusts the logits of a classifier before applying the softmax. By dividing each logit by a temperature parameter T>1, the softmax output becomes flatter, reducing the model’s overconfidence. Because the same scaling factor is applied to all logits, their relative differences are preserved, so the rank of the predicted classes—and thus the argmax decision—remains unchanged. The optimal temperature is usually found by minimizing the negative log‑likelihood on a held‑out validation set, ensuring the calibrated probabilities are as close as possible to true likelihoods.

</details>
