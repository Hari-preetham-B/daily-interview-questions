# 2026-10-12 AM — AIML (Medium)

## Question
How would you detect and prevent data leakage in a supervised learning pipeline? Give a concrete example where leakage could occur during preprocessing and explain how you would modify the pipeline to eliminate it.

## Hint
Think about the order in which you split data and apply transformations such as scaling or feature engineering.

## Answer
Data leakage occurs when information from the test set influences the training process, leading to overly optimistic performance. A common scenario is scaling or normalizing features after the train-test split: if you compute mean/variance on the entire dataset, the test data stats leak into training. To fix this, perform the split first, then fit transformers (e.g., StandardScaler, Imputer, PCA) only on the training data, and apply the fitted transformers to the test set. Likewise, avoid creating derived features that depend on future labels or on the full dataset. Validating the pipeline with cross‑validation after fitting transformations ensures leakage is avoided.
