# 2026-11-12 AM — DSA (Medium)

## Question
Given an integer array nums, find the length of the longest arithmetic subsequence (not necessarily contiguous). An arithmetic subsequence is a sequence of at least two indices i1 < i2 < ... < ik such that the difference nums[i_j] - nums[i_{j-1}] is the same for all j>1. Return the maximum possible length; if no arithmetic subsequence of length ≥ 2 exists, return 0.

## Hint
For each index i, maintain a map from difference d to the length of the longest arithmetic subsequence ending at i with that difference. Update these maps by examining all previous indices j < i.

## Answer
We can solve it in O(n^2) time using DP. Create an array dp where dp[i] is a hash map: dp[i][d] stores the length of the longest arithmetic subsequence ending at index i with common difference d. Iterate i from 0 to n-1, and for each j < i compute d = nums[i] - nums[j]. If dp[j] contains d, set dp[i][d] = dp[j][d] + 1; otherwise start a new subsequence of length 2 (dp[i][d] = 2). Keep a global maximum of all dp[i][d] values. After processing, if the maximum is still 2 and n < 2, return 0; otherwise return the maximum length found. The algorithm runs in O(n^2) time and uses O(n^2) space in the worst case.
